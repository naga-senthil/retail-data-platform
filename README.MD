# Retail Data Platform

## Objective

Build an enterprise-grade data platform using the Olist E-Commerce Dataset and Snowflake.

## Features

- Data Ingestion
- Staging Layer
- Data Quality Framework
- Star Schema
- Monitoring & Observability
- Dependency Management
- Retry Logic
- Reconciliation
- SLA Tracking
- Dashboarding

## Technology Stack

- Snowflake
- SQL
- Python
- GitHub
- Power BI
